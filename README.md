# Paradise Nursery Shopping Application

Paradise Nursery is an online plant shop built with React and Redux.

## Features

- **Landing page** with a background image, the company name and a "Get Started" button.
- **About Us** section describing Paradise Nursery.
- **Product listing page** with houseplants grouped into categories. Each plant shows a thumbnail, name, description and price, and has an "Add to Cart" button.
- **Shopping cart page** that shows each plant's thumbnail, name, unit price, quantity and total cost, plus the total cart amount. Users can increase or decrease quantities, delete items, check out (coming soon) or continue shopping.
- **Navbar** with links to Home, Plants and Cart, and a cart icon that shows the number of items in the cart.

## Tech stack

- React (Vite)
- Redux Toolkit and React Redux for the shopping cart state

## Run locally

```bash
npm install
npm run dev
```
